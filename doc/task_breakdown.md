# SQL Query Builder Task Breakdown

## 1. Tables (2 hours)
- Add functionality to display a list of database tables.
- Add functionality to select or remove tables for the query.

---

## 2. Joins (3 hours)
- Implement automatic detection of possible joins based on foreign keys.
- Add functionality to manually configure joins with conditions and types (`INNER JOIN`, `LEFT JOIN`, etc.).
- Add functionality to modify or delete joins.

---

## 3. Columns (2 hours)
- Implement display of available columns for selected tables.
- Add functionality to select columns for inclusion in the query.
- Add functionality to remove selected columns.

---

## 4. Filters (2 hours)
- Add functionality to create, edit and delete filters (`WHERE` conditions) with columns, operators, and values.
- Add functionality to use logical operators (`AND`, `OR`) and group conditions.

---

## 5. Sorting and grouping (2 hours)
- Add functionality to select sorting columns and direction (`ASC`, `DESC`).
- Add functionality to configure grouping (`GROUP BY`).
- Add functionality to apply aggregate functions (`SUM`, `AVG`, `COUNT`, etc.).

---

## 6. Generating and executing an SQL query (2 hours)
- Implement automatic SQL query generation based on user input.
- Implement inclusion of tables, joins, columns, filters, sorting, and grouping in the query.

---

## 7. Error handling (3 hours)
- Implement automatic removal of related joins, filters, sorting, and grouping when dependent elements are removed.
